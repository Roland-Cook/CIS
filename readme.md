Digital Closet Inventory System

A simple, lightweight console app built in Java to track your wardrobe. It saves your items locally using a CSV file (closet_data.csv) so your inventory persists between sessions.

Requirements

    Java Development Kit (JDK) installed on your machine.

How to Run

You can run this project either via the command line or by opening it in your favorite IDE (like VS Code).
Option 1: Using the Terminal (Command Line)

    Clone or download this repository to your local machine.

    Open your terminal and navigate to the folder containing DigitalClosetApp.java.

    Compile the Java source file:

    javac DigitalClosetApp.java

    Run the application:

    java DigitalClosetApp

Option 2: Using an IDE (e.g., VS Code)

    Clone or download this repository to your local machine.

    Open the project folder in your IDE.

    Open DigitalClosetApp.java.

    Click the Run button or use your IDE's built in execution tool.
